# Lukla Data Studio: feedback

Bug reports, feature requests and crash reports for [Lukla Data Studio](https://datastudio.luklalogic.ai), a native SQL Server tool for macOS.

**The easiest way to file one is from the app:** Help ▸ Report a Problem… or Help ▸ Request a Feature…. The app adds the versions that matter and gives you the link to the issue it creates. You can also open an issue here directly.

- 👍 a request to vote for it. Requests with the most votes get looked at first.
- Search before filing: your problem may already be known, with a workaround.
- Don't post passwords, server names, connection strings or data. Issues here are public.

Issues labelled `from-app` were sent from the app. Their screenshots and reply emails are kept privately, not here. `crash` issues are filed automatically when a user chooses to send a crash report, and repeats of the same crash are added as comments.

How it works and what's sent: [datastudio.luklalogic.ai/docs/feedback](https://datastudio.luklalogic.ai/docs/feedback/).

Prefer email? [support@luklalogic.ai](mailto:support@luklalogic.ai)
